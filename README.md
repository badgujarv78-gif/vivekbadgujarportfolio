# Vivek Badgujar — Portfolio Website

A responsive, single-page portfolio website built with HTML, CSS and JavaScript.

## Before publishing
1. Add your professional photo as `assets/profile-photo.jpg`.
2. In `index.html`, replace `your.email@example.com` with your email address.
3. Replace the sample project cards with your real work and links.
4. Replace the LinkedIn and YouTube placeholder links with your profile URLs.
5. Confirm every project is yours and that you have permission to show client work.

## Publish with GitHub
1. Create a repository named `vivek-video-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.

You can also import the repository into Vercel and deploy it as a static site. No build command is needed.
